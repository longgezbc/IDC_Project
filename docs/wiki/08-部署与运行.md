## 1. 容器拓扑（5 个服务）

| 服务 | 容器 | 镜像/构建 | 端口 | 内存上限 | 说明 |
|------|------|-----------|------|----------|------|
| mysql | hbsz-mysql | mysql:8.0.40（固定 LTS tag） | 内部 3306（默认不暴露） | 400M | utf8mb4、buffer_pool=128M、慢查询日志(>3s)、数据卷 hbsz-mysql-data |
| mysql-grants | hbsz-mysql-grants | mysql:8.0.40 | - | - | **一次性任务**：等 MySQL 就绪 → 同步 hbsz_app 密码（与 .env.docker 一致）→ 执行 init-grants.sql，完成后退出 |
| redis | hbsz-redis | redis:7.2-alpine | 内部 6379 | 80M | requirepass、maxmemory 48mb、allkeys-lru、AOF everysec |
| backend | hbsz-backend | ./Hbsz_IDC_System_end（本地 mvn package 的 JAR） | **127.0.0.1:**${BACKEND_PORT:-8080} → 8080（仅本机回环，不公网暴露） | 288M | JVM `-Xms96m -Xmx160m -XX:+UseSerialGC`；cap_drop ALL、read_only、tmpfs、非 root appuser |
| frontend | hbsz-frontend | ./Hbsz_IDC_System（本地 npm run build 的 dist + nginx） | ${FRONTEND_PORT:-80} → 8080（唯一公网入口） | 32M | nginx 非 root 监听 8080；依赖 backend 健康检查；App/小程序 API 均经此反代；**dist/downloads/（APK + app-latest.json）随镜像一同 COPY 打入，自包含分发** |

依赖顺序：mysql(healthy) + redis(healthy) + mysql-grants(success) → backend(healthy) → frontend。

网络：`hbsz-network`（bridge）。数据卷：`hbsz-mysql-data / hbsz-redis-data / hbsz-uploads-data / hbsz-logs-data`。

## 2. 环境变量（.env.docker，必填项强制）

| 变量 | 必填 | 说明 |
|------|------|------|
| MYSQL_ROOT_PASSWORD | 是 | MySQL root 密码 |
| MYSQL_DATABASE | 否（默认 hbsz_idc_system） | 库名 |
| DB_USERNAME / DB_PASSWORD | DB_PASSWORD 必填 | 应用账号（hbsz_app） |
| REDIS_PASSWORD | 是 | Redis 密码 |
| JWT_SECRET | 是 | JWT 签名密钥（2026-08-22 已轮换为 64-hex，仅存于服务器 .env.docker） |
| CORS_ALLOWED_ORIGINS | 否 | 允许的前端源 |
| BACKEND_PORT / FRONTEND_PORT | 否（8080 / 80） | 宿主机端口 |

> 所有 compose 命令必须带 `--env-file .env.docker`（未设置必填变量时 compose 直接拒绝启动）。**严禁将本地 `.env.docker` 上传覆盖生产密码文件。**

## 3. Nginx 关键规则（Hbsz_IDC_System/nginx.conf）

| 规则 | 目的 |
|------|------|
| `^~ /api/` → `proxy_pass http://backend:8080/api/` | **前缀匹配优先于正则**，防止 `/api/files/preview/xxx.png` 被静态规则截获 |
| `^~ /ws/` → WebSocket 代理（http 1.1 + Upgrade 头，86400s 超时） | STOMP 实时通知 |
| `location / { try_files $uri $uri/ /index.html; }` | Vue History 路由回退；同时覆盖 `/downloads/*` 静态资源（APK 自更新） |
| 静态资源 `expires 1y + immutable`；`index.html` no-cache | hash 文件名 + 入口不缓存，支持增量发布 |
| `= /api/actuator/health` 放行、`^~ /api/actuator` 404 | 仅暴露健康检查 |
| 拦截 `.env/.git`、可执行扩展名（php/jsp/exe…） | 信息泄露 / WebShell 纵深防御 |
| gzip、安全头（CSP/XFO/nosniff）、`server_tokens off` | 传输与响应安全 |

## 5. 生产构建产物

| 端 | 命令 | 产物 | 要求 |
|----|------|------|------|
| 后端 | `mvn clean package` | `Hbsz_IDC_System_end/target/*.jar`（约 82MB） | **134 个测试全通过**（含 `ProjectServiceImplManagerLinkTest` ×4，2026-08-22 新增）；启动时 Flyway 自动迁移 |
| 前端 | `npm run build` | `Hbsz_IDC_System/dist/`（index.html + assets + downloads/） | 0 sourcemap、hash 文件名、包含全部 UI 优化；构建前置：ESLint 0 error/0 warning、vitest 45 个用例全绿；`dist/downloads/` 需含 `app-latest.json` 与当前 APK（自包含分发） |
| Android | `.\gradlew assembleRelease` | APK（约 19.6MB debug） | 分发新 APK 才能获得新功能；当前发布版 v1.0.3（versionCode 4，`dist_apk/Hbsz_IDC_v1.0.3_20260823.apk`） |

> **构建产物时效自检**：发布前务必对比源码与 dist 的 mtime——若 dist 落后于 src（源码改动后未重新 build），会导致线上跑旧代码。2026-08-23 重部署即因 local dist 落后于 src（5 个文件在最近 build 后被改）而需 rebuild 前端。

## 6. 生产部署流程（本地构建 → 上传 → 重建）

```bash
# 服务器侧（ubuntu + pem 密钥登录）
# 1. 备份
cp -r /path/backup mysql 与旧 JAR、旧 dist（backup/<日期>_<主题>/）
# 2. 上传：后端 JAR、前端 dist/ 全部内容（index.html + assets + downloads/）到 web 根
# 3. 重建后端容器
docker compose --env-file .env.docker up -d --build backend
# 4. 前端容器重建
docker compose --env-file .env.docker up -d --build frontend
```

部署顺序硬约束：**先部署后端 JAR（触发 Flyway 迁移）→ 再部署前端 dist**，防止前端新页面查询缺失列报 `Unknown column`。

### 6.1 零停机重部署判定（2026-08-23 经验）

- **后端 JAR hash 与线上一致** → compose 检测无漂移 → 不重建不重启 → **零停机**（迁移脚本未变时安全）
- **前端 dist 落后于 src** → 必须 `--build frontend`（dist 是 COPY 进镜像，restart 不生效）
- App 自更新分发：改 `app-latest.json`/换 APK 后同样必须 `--build frontend`，仅 restart 不生效

回滚约定：每次部署前在服务器 `~/hbsz/backup/<日期>_<主题>/` 归档旧产物（如 `old_dist.tar.gz`、旧 JAR），出问题时先恢复备份再重建对应容器。2026-08-23 重部署已留 `backup/20260823_redeploy/` 回滚点。

## 9. 运维坑位备忘

- **Windows ssh 引号陷阱**：经 PowerShell 执行 `tr -d "\r"` 会被解析成 `tr -d "r"`（删除所有字母 r）；`docker ps --format "{{...}}"` 间歇性失败——改用 plain `docker ps` 后解析
- **Fingerprint 白屏**：前端 icons.js 增删图标时，import 块与 icons 数组两处必须同步，否则 Rollup 把未定义标识符当全局变量（构建通过）→ 运行时 ReferenceError 致整站白屏（详见 05 §7）
- **JWT_SECRET**：2026-08-22 已轮换；本地 .env.docker 严禁覆盖生产
