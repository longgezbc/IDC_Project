## 2. 分层架构

```
Controller（REST，/api/v1/**）
    │  @RequiresPermission / @OperationLog / @Idempotent / @RateLimit
    ▼
Service 接口 (I*Service) ──► ServiceImpl（业务逻辑、事务）
    │                          │  辅助：ProjectAccessGuard、ProjectTransferLogHelper、
    │                          │        AssignmentRevokeService、NotificationPushService
    ▼                          ▼
Mapper（MyBatis-Plus BaseMapper + XML）──► MySQL（hbsz_idc_system）
```

横切关注点（`aspect/`、`interceptor/`、`config/`）见下文第 5-7 节。

## 3. 配置体系

### 3.1 配置文件

- [application.yml](file:///c:/Users/QianLong/Desktop/Hbsz/Hbsz_IDC_System_end/src/main/resources/application.yml)：公共配置
  - `server.servlet.context-path: /api`；`api.version.current: v1`（接口统一 `/api/v1/` 前缀）
  - 文件上传 `max-file-size: 100MB`（与 Nginx `client_max_body_size 100m`、`FileStorageServiceImpl` 上限一致）
  - Flyway：`locations: classpath:db/migration`、`baseline-on-migrate: true`、`validate-on-migrate: false`（历史脚本幂等）
  - MyBatis-Plus：逻辑删除字段 `deleted`（1 删除 / 0 正常）
  - Knife4j：中文文档、扫描 controller 包
  - `hbsz.jwt.issuer / audience`：从环境变量 `JWT_ISSUER/JWT_AUDIENCE` 注入
- `application-dev.yml` / `application-prod.yml`：profile 差异配置；**profile 必须由 `SPRING_PROFILES_ACTIVE` 指定，无默认值**（防止开发配置上生产）

### 3.2 生产环境变量（docker-compose 注入）

| 变量 | 说明 |
|------|------|
| `DB_URL` / `DB_USERNAME` / `DB_PASSWORD` | MySQL 连接（用户 `hbsz_app`） |
| `REDIS_HOST/PORT/PASSWORD/DB` | Redis 连接 |
| `JWT_SECRET` | JWT 签名密钥（必填强制） |
| `JWT_EXPIRATION` | access token 有效期（默认 1800000ms = 30min） |
| `JWT_REFRESH_EXPIRATION` | refresh token 有效期（604800000ms = 7d） |
| `CORS_ALLOWED_ORIGINS` | 允许的前端源 |
| `HBSZ_FILE_UPLOAD_DIR` | 上传根目录（容器内 `/app/uploads`） |

### 3.3 线程池与连接池硬约束

- Tomcat：`max=60`、`min-spare=10`（显式配置）
- Druid：`max-active=15`
- Lettuce：`max-wait=2000ms`
- JVM（容器）：`-Xms96m -Xmx160m -XX:+UseSerialGC`（2G 服务器省内存）

## 4. 认证与安全体系

### 4.1 JWT 认证

| 组件 | 文件 | 职责 |
|------|------|------|
| JwtUtils | [utils/JwtUtils.java](file:///c:/Users/QianLong/Desktop/Hbsz/Hbsz_IDC_System_end/src/main/java/com/example/hbsz_idc_system_end/utils/JwtUtils.java) | 生成 access/refresh token（claims：userId/username/name/type），解析时校验签名 + issuer + audience，失败返回 null |
| JwtAuthInterceptor | [interceptor/JwtAuthInterceptor.java](file:///c:/Users/QianLong/Desktop/Hbsz/Hbsz_IDC_System_end/src/main/java/com/example/hbsz_idc_system_end/interceptor/JwtAuthInterceptor.java) | 校验 `Authorization: Bearer`；检查 Redis 黑名单与过期；通过后写入 `UserContext`；放行 OPTIONS、`/system/config`（路由切换防误杀）、验证码等公开端点 |
| UserContext | utils/UserContext.java | ThreadLocal 保存 userId/username，业务层随时取当前用户 |
| 登录验证码 | CaptchaController + LoginDTO | `captchaId + captcha` 必填；校验失败**不**递增锁定计数 |

登录流程（`AuthController` → `AuthServiceImpl`）：
`/captcha` 获取验证码 → `/auth/login`（校验验证码 → 校验账号密码/锁定状态 → 签发双 token）→ `/auth/refresh` 无感续期 → `/auth/logout` 将 token 加入 Redis 黑名单。

### 4.2 RBAC 权限模型

```
SysUser ──(sys_user_role)── SysRole ──(sys_role_permission)── SysPermission
   │
   └── SysPosition（岗位，用于职级校验）
```

- 注解 [common/annotation/RequiresPermission.java](file:///c:/Users/QianLong/Desktop/Hbsz/Hbsz_IDC_System_end/src/main/java/com/example/hbsz_idc_system_end/common/annotation/RequiresPermission.java)：`value()`（权限码）、`logicalAnd()`（AND/OR 组合）、`requirePosition()`（岗位编码白名单）
- 切面 [aspect/PermissionAspect.java](file:///c:/Users/QianLong/Desktop/Hbsz/Hbsz_IDC_System_end/src/main/java/com/example/hbsz_idc_system_end/aspect/PermissionAspect.java)：调用 `PermissionService.checkPermissions` 校验；超级管理员跳过；岗位不符抛 `FORBIDDEN`
- 前端对应：路由 `meta.permission` + `utils/permission.js`（`hasPermission`/`isAdmin`），菜单与路由双重拦截

### 4.3 数据隔离与访问守卫

- [service/ProjectAccessGuard.java](file:///c:/Users/QianLong/Desktop/Hbsz/Hbsz_IDC_System_end/src/main/java/com/example/hbsz_idc_system_end/service/ProjectAccessGuard.java)：项目级访问控制（项目经理/授权工程师/项目组成员可见）

## 10. 本地运行

```powershell
# 前置：MySQL 8 + Redis 已启动，或直接使用根目录 docker-compose 的 mysql/redis 服务
cd Hbsz_IDC_System_end

# 方式一：开发 profile
$env:SPRING_PROFILES_ACTIVE="dev"; mvn spring-boot:run

# 方式二：打包后运行（生产）
mvn clean package -DskipTests=false   # 全量测试通过后产出 JAR
java -jar target/hbsz-idc-system-end-*.jar
```

- 服务端口：`8080`，context-path `/api`，接口前缀 `/api/v1/`
- API 文档：`http://localhost:8080/api/doc.html`（Knife4j）
- 首次启动 Flyway 自动建表迁移；数据库账号见 `application-dev.yml`
