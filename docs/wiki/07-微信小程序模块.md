# 07 - 微信小程序模块

> 模块路径：`hbsz_-uniapp_-vue-master/`
> 框架：uni-app（Vue 3），编译目标为微信小程序（mp-weixin）
> 技术定位：现场工程师的轻量移动端（进度/工作量填报、审批、资料查看）

---

## 1. 工程配置

- [manifest.json](file:///c:/Users/QianLong/Desktop/Hbsz/hbsz_-uniapp_-vue-master/manifest.json)：应用名/版本、mp-weixin 配置（**生产 urlCheck 必须为 true**，AppID 不能用游客模式，否则网络请求超时）
- [pages.json](file:///c:/Users/QianLong/Desktop/Hbsz/hbsz_-uniapp_-vue-master/pages.json)：页面路由表 + 全局样式 + tabBar
- `utils/config.js`：`API_BASE_URL`（**必须 HTTPS 域名**），小程序后台需配置 request/socket/uploadFile/downloadFile 合法域名
- tabBar（4 项，**图标仅 PNG/JPG**，static/icon/ 下的 SVG 仅用于页面内）：工作台、项目、资料、我的

## 4. 工具层（utils/）

| 模块 | 职责 |
|------|------|
| request.js | 请求封装：自动附带 token、**401 刷新队列**（并发 401 挂起等待，`refreshAccessToken()` 用 refreshToken 调 `/auth/refresh`，成功保存新 token 并重放请求，失败清空队列跳登录）——与 Web 端共享同一套算法（`shared/tokenRefreshCoordinator.js`） |
| auth.js | Token/RefreshToken/用户信息本地存储与登录态判断 |
| config.js | API_BASE_URL 等环境配置 |
| ws.js | WebSocket 通知接入 |
| permission.js | 权限判断（页面级 v-if 控制） |
| format.js | 格式化（与 `shared/format.js` 同源的**手动同步副本**） |

## 5. 与后端的对接

- 接口前缀同其他端：`/api/v1/*`；认证体系一致（JWT 双 token + 验证码登录）
- 上传走 `uni.uploadFile`（需在小程序后台配置 uploadFile 合法域名）
- 文件预览/下载走 downloadFile 域名

## 6. 运行与发布

```powershell
# HBuilderX 导入工程 → 运行到微信开发者工具（需配置真实 AppID）
# 或使用 cli：
npm install -g @dcloudio/uvm
# 发行：HBuilderX → 发行 → 小程序-微信 → 上传体验版/审核
```

注意事项（来自项目约束）：
- 生产 `manifest.json` 的 `mp-weixin.appid` 必须为真实 AppID，`urlCheck: true`
- 服务器域名（request/socket/uploadFile/downloadFile）需在小程序管理后台白名单
- tabBar 图标必须 PNG/JPG 格式
