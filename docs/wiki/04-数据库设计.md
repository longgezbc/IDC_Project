# 04 - 数据库设计

> 数据库：MySQL 8.0（utf8mb4），库名 `hbsz_idc_system`
> 初始化：`docker/mysql/01-schema.sql`（建库/建用户）+ `02-seed-data.sql`（种子数据）
> 版本演进：Flyway（`Hbsz_IDC_System_end/src/main/resources/db/migration/`），后端启动自动执行
> 文档版本：v4.0（2026-08-23）

---

## 1. 实体与表清单

命名约定：`sys_` 系统域、`biz_` 业务域；所有表含 `BaseEntity` 公共字段（id、create_time、update_time、create_by、update_by、deleted 逻辑删除）。实体类位于 `entity/` 包。

### 1.1 系统域（sys_*）

| 实体 | 表 | 说明 |
|------|-----|------|
| SysUser | sys_user | 用户（含锁定状态、岗位关联） |
| SysRole | sys_role | 角色（1=超级管理员，2=项目经理…） |
| SysPermission | sys_permission | 权限点（如 ID=11 `system:user:query`） |
| SysUserRole | sys_user_role | 用户-角色 |
| SysRolePermission | sys_role_permission | 角色-权限 |
| SysPosition | sys_position | 岗位（职级校验用） |
| SysOperationLog | sys_operation_log | 操作审计（@OperationLog 落库） |
| SysNotification | sys_notification | 站内通知 |
| SysNotificationConfig | sys_notification_config | 用户通知偏好 |
| SysSystemConfig | sys_system_config | 系统配置（DB 持久化） |

### 1.2 业务域（biz_*）

| 实体 | 表 | 说明 |
|------|-----|------|
| BizProject | biz_project | 项目主表（含 region、manager_assignee_ids、乐观锁 version） |
| BizProjectTeam | biz_project_team | 项目组 |
| BizProjectAssignment | biz_project_assignment | 项目授权关系（project+engineer+scope，活跃唯一索引 `uk_project_engineer_active`） |
| BizProjectAuthRequest | biz_project_auth_request | 授权申请（pending 唯一守卫） |
| BizProjectTransferLog | biz_project_transfer_log | 项目转移审计日志（operated_by 可空，V20260820.1） |
| BizTask | biz_task | 任务（树形结构、计划/实际日期、进度） |
| BizTaskProgressLog | biz_task_progress_log | 进度填报日志（pending → approved/rejected，含施工图片） |
| BizDocument | biz_document | 文档 |
| BizDocumentVersion | biz_document_version | 文档版本 |
| BizDocumentTag / BizDocumentTagRelation | biz_document_tag(_relation) | 文档标签 |
| BizDesignDrawing | biz_design_drawing | 设计图纸 |
| BizCustomer | biz_customer | 客户（phone 可空，V20260726） |
| BizArchiveRecord | biz_archive_record | 归档记录 |
| BizExportRecord | biz_export_record | 导出记录（日报等） |
| BizWorkloadItem | biz_workload_item | 工作量清单（106 标准条目） |
| BizWorkloadRecord | biz_workload_record | 工作量填报记录（pending → approved/rejected） |

### 1.3 核心关系（ER 摘要）

```
sys_user ──< sys_user_role >── sys_role ──< sys_role_permission >── sys_permission
   │
   └─(position_id)─ sys_position

biz_customer ──< biz_project >── biz_project_team ──< sys_user
                     │        │
   biz_project_assignment ────┤（project+engineer 唯一活跃）
   biz_project_auth_request ──┤
   biz_project_transfer_log ──┤
                     │
                biz_task ──< biz_task_progress_log（审核流）
                     │
                biz_document ──< biz_document_version / tag_relation
                biz_workload_item ──< biz_workload_record（项目+人员+日期）
```

## 4. 初始化与账号

- `docker/mysql/01-schema.sql`：创建 `hbsz_idc_system` 库、`hbsz_app` 应用账号并授权
- `docker/mysql/02-seed-data.sql`：初始角色/权限/管理员账号/字典数据
- `docker/mysql/init-grants.sql`：**每次部署执行**，同步 `hbsz_app` 密码与 `.env.docker` 一致并刷新授权（由 compose 的 `mysql-grants` 一次性服务执行，解决数据卷复用时 01-schema 不重跑导致的权限缺失）
- `docker/mysql/my.cnf`：MySQL 容器参数

## 5. 变更流程约定

1. 新增/修改表结构 → 在 `db/migration/` 新建 `V{当天日期}__desc.sql`，必须幂等
2. 同步更新对应 Entity（逻辑删除 deleted、驼峰映射）
3. 后端启动自动迁移；**生产部署顺序：先部署后端 JAR（触发迁移）→ 再部署前端 dist**（防止前端新页面查询缺失列报 `Unknown column`）
