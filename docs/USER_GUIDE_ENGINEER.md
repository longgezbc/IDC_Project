# IDC 数据中心综合布线项目管理系统 - 工程师使用手册

> 本手册面向"工程师"角色用户，指导其在 Web 端与微信小程序端完成日常操作。
> 适用版本：v1.1 ｜ 最后更新：2026-07-15

---

## 系统概述

本系统为 IDC 数据中心综合布线项目管理平台，包含三端：

| 端 | 技术栈 | 访问方式 |
| --- | --- | --- |
| Web 端 | Vue3 + Element Plus | 浏览器访问 `http://服务器IP/` |
| 微信小程序 | uni-app | 微信搜索「IDC项目管家」 |
| 后端 | Spring Boot | 提供 RESTful API 与 WebSocket 服务 |

## 角色信息

- **角色名称**：工程师
- **角色代码**：`engineer`
- **角色定位**：执行具体任务，可查询项目、上传文档、查询任务并填报进度

## 一、角色定位与权限范围

### 1.1 角色职责定位

工程师是系统的**任务执行者**，主要职责为：

- 接收项目经理（PM）分配的项目任务
- 按时填报施工进度，上传施工现场图片
- 上传施工相关文档资料
- 跟进任务审核结果

工程师**不具备**审批、删除、创建任务等管理权限。

## 二、核心功能操作指南

### 2.1 查看我的任务

**操作路径**：Web 端 → 进度任务 → 我的任务

**操作步骤**：

1. 登录系统后，点击左侧菜单「进度任务」
2. 在子菜单中点击「我的任务」
3. 系统默认展示**分配给当前登录工程师**的任务列表
4. 可通过顶部筛选条件（项目名称、任务状态、时间范围）快速过滤
5. 点击任务名称可查看任务详情（包含任务描述、计划起止时间、当前进度等）

**注意事项**：

- 「我的任务」仅展示分配给您的任务，不会显示他人任务
- 任务状态包含：待开始、进行中、待审核、已完成、已驳回
- 任务详情页可直接点击「填报进度」进入填报流程

---

### 2.2 进度填报（重点功能）

**操作路径**：Web 端 → 进度任务 → 我的任务 → 点击「填报进度」

或：小程序端 → 进度填报

**操作步骤**：

1. 在「我的任务」列表中找到要进行进度填报的任务
2. 点击任务行右侧的「填报进度」按钮，弹出填报对话框
3. **填写进度百分比**：
   - 可手动输入 0-100 之间的整数
   - 可使用快捷进度按钮：`25%` / `50%` / `75%` / `100%`
4. **上传施工图片**（必填）：
   - 点击上传区域选择图片文件
   - 最多支持上传 **6 张** 施工图片
   - 单张图片大小不超过 **10MB**
   - 支持格式：JPG / JPEG / PNG
5. **填写工作量描述**（必填）：
   - 文本框中详细描述本次完成的工作内容、施工部位、关键节点等
6. **填写工时**：
   - 输入本次填报消耗工时（支持小数，如 `0.5` 小时）
   - 可使用快捷按钮：`4h` / `8h` / `12h`
7. 检查信息无误后，点击「提交」按钮

**注意事项**：

- ⚠️ **必须上传施工图片**，否则无法提交
- ⚠️ **必须填写工作量描述**，否则无法提交
- ⚠️ 提交后进度不会立即更新，需**项目经理审核通过**后才会更新任务进度
- ⚠️ 同一任务在审核完成或驳回前**不可重复提交**新的进度填报
- 审核被驳回时，需根据驳回原因修改后重新提交

---

### 2.3 查看填报历史

**操作路径**：Web 端 → 进度任务 → 我的填报历史

或：小程序端 → 我的填报历史

**操作步骤**：

1. 点击左侧菜单「进度任务」→「我的填报历史」
2. 列表展示当前工程师所有历史填报记录，包含：
   - 任务名称、所属项目
   - 填报时间
   - 填报进度百分比
   - 审核状态（待审核 / 审核通过 / 审核驳回）
   - 审核意见（如被驳回会显示 PM 的驳回原因）
3. 可按时间、项目、审核状态筛选历史记录
4. 点击单条记录可查看详情（含已上传的施工图片、工作量描述、工时等）

**注意事项**：

- 填报历史为只读，不可修改已提交的记录
- 若需修改，应在「待审核」状态下联系 PM 驳回后重新填报

---

### 2.4 申请项目授权

**操作路径**：Web 端 → 项目协作 → 申请项目授权

**操作步骤**：

1. 点击左侧菜单「项目协作」→「申请项目授权」
2. 在可申请项目列表中，选择需要查看的目标项目
3. 填写授权申请说明（如：申请查看该项目的理由、需要的协助事项）
4. 点击「提交申请」
5. 申请将发送至该项目的**项目经理（PM）** 进行审批
6. PM 审批通过后，您将获得该项目的查看权限，并可在「项目管理」中查看该项目详情
7. 申请进度可在列表中实时查看（待审批 / 已通过 / 已驳回）

**注意事项**：

- 仅当项目可见范围为 `assignment`（按授权可见）时需要申请
- 项目可见范围为 `team`（项目组内可见）时，加入项目组即可查看
- 项目可见范围为 `public`（全公司可见）时，无需申请即可查看
- 申请被驳回可查看驳回原因，修改后可重新提交

---

### 2.5 上传文档

**操作路径**：Web 端 → 文档管理 → 上传

**操作步骤**：

1. 点击左侧菜单「文档管理」
2. 在顶部选择关联的项目（必选）
3. 点击「上传」按钮，弹出上传对话框
4. 选择要上传的文件（可拖拽或点击选择）
   - 支持格式：`PDF` / `DOCX` / `XLSX` / `DWG` 等
   - 单文件大小不超过 **100MB**
5. 填写文档信息：
   - 文档名称（必填）
   - 文档分类（如：施工图、验收资料、技术方案等，必填）
   - 文档版本（可选）
   - 备注（可选）
6. 点击「提交」完成上传

**注意事项**：

- ⚠️ 工程师上传的文档**不可被自己删除**（无 `document:remove` 权限）
- ⚠️ 不可编辑/删除他人上传的文档
- 仅可下载有权限查看的文档
- 大文件上传请保持网络稳定，建议使用 Chrome / Edge 浏览器

---

### 2.6 工作量管理（v1.1 新增）

v1.1 版本新增工作量管理机制，工程师在填报进度时需提交「本次完成工作量」，由 PM 审核通过后累加到任务的实际完成工作量（actualWorkload）。

#### 2.6.1 填报本次完成工作量

**操作路径**：Web 端 → 进度任务 → 我的任务 → 点击「填报进度」

或：小程序端 → 进度填报

在进度填报对话框中，除原有的进度百分比、施工图片、工时外，新增必填项**「本次完成工作量」**，并与已有的**「工作量描述」**配合提交：

| 字段 | 字段名 | 说明 | 是否必填 |
|------|--------|------|---------|
| 本次完成工作量 | workloadHours | 本次填报完成的工作量数值（v1.1 新增字段） | ✅ |
| 工作量描述 | workloadDescription | 描述本次完成的工作内容、施工部位、关键节点等 | ✅ |

**操作步骤**：

1. 在「我的任务」中找到目标任务，点击「填报进度」。
2. 填写进度百分比、上传施工图片（与原流程一致）。
3. **填写本次完成工作量**：
   - 查看任务详情中 PM 设定的「工作量单位」（如条/个/台/芯/端口/机架/米/人天）。
   - 按该单位填写本次实际完成的数量（如单位为「条」，本次布线 12 条，则填 `12`）。
4. **填写工作量描述**：详细描述本次完成的工作内容、施工部位、关键节点等。
5. 检查信息无误后，点击「提交」。

> ⚠️ **本次完成工作量必须真实准确**，PM 审核通过后会自动累加到任务的实际完成工作量，虚报将导致项目工作量统计失真。
> ⚠️ 提交后需 PM 审核通过才会累加工作量；驳回则不累加，需根据驳回原因修改后重新提交。
> 💡 「工作量描述」用于辅助 PM 核对工作量，建议填写具体施工部位与完成数量明细，便于审核通过。

## 四、注意事项与限制条件

### 4.1 进度填报限制

1. **必填项强制校验**：进度填报必须上传施工图片和填写工作量描述，否则系统不允许提交。
2. **审核机制**：进度填报提交后需项目经理审核通过才会更新任务进度，未审核前任务进度不会显示新进度。
3. **不可重复提交**：同一任务在审核完成或驳回前，不可重复提交进度填报。
4. **图片限制**：单次最多上传 6 张施工图片，单张不超过 10MB。
5. **工时格式**：工时支持小数（如 `0.5` 小时），快捷按钮 `4h` / `8h` / `12h`。

### 4.2 任务操作限制

6. **不可创建任务**：工程师不可创建/编辑/删除任务，只能对分配给自己的任务进行填报。
7. **不可审核**：工程师无审核权限，无法审批他人进度。

### 4.3 项目可见范围限制

8. **仅可见授权项目**：工程师只能查看自己被授权的项目（`team_scope=assignment` 时仅授权可见）。
9. **项目可见范围说明**：
   - `assignment`：仅授权可见（需 PM 单独授权或申请授权）
   - `team`：项目组内可见（加入项目组即可查看）
   - `public`：全公司可见（无需授权即可查看）

### 4.4 文档操作限制

10. **格式与大小**：文档上传支持 `PDF` / `DOCX` / `XLSX` / `DWG` 等格式，单文件不超过 **100MB**。
11. **不可删除文档**：工程师上传的文档不可被自己删除（无 `document:remove` 权限），如需删除请联系项目经理或系统管理员。
12. **不可编辑他人文档**：仅可下载有权限查看的文档，不可编辑/删除他人上传的文档。

## 五、问题排查与支持渠道

### 5.1 常见问题 FAQ

#### Q1：为什么我看不到某个项目？

**可能原因与解决方案**：

- 该项目可见范围为 `assignment`（按授权可见），您尚未获得授权
  → 解决：通过「项目协作 → 申请项目授权」向 PM 发起授权申请
- 该项目可见范围为 `team`（项目组内可见），您未加入该项目组
  → 解决：联系项目经理将您加入项目组
- 该项目已归档
  → 解决：到「归档管理」中查看归档记录
- 账号角色权限配置有误
  → 解决：联系系统管理员核查权限

#### Q2：进度填报提交失败，提示必填项未填写？

**可能原因**：未上传施工图片，或未填写工作量描述。

**解决方案**：

- 检查是否已上传至少 1 张施工图片
- 检查工作量描述文本框是否为空
- 补全后重新提交

#### Q3：施工图片上传失败？

**可能原因与解决方案**：

- 图片超过 10MB → 压缩后重新上传
- 图片格式不支持 → 转换为 JPG / JPEG / PNG 格式
- 网络不稳定 → 切换网络后重试
- 浏览器兼容性问题 → 推荐使用 Chrome 或 Edge 最新版本

#### Q4：进度填报审核被驳回怎么办？

**解决方案**：

1. 进入「进度任务 → 我的填报历史」
2. 找到对应填报记录，查看 PM 的驳回原因
3. 在「我的任务」中找到该任务，点击「填报进度」
4. 根据驳回原因修改填报内容（进度、图片、描述等）
5. 重新提交

#### Q5：同一任务无法再次提交进度填报？

**原因**：同一任务在审核完成或驳回前不可重复提交。

**解决方案**：

- 等待 PM 完成审核（通过或驳回）
- 若急需修改，可联系 PM 主动驳回您的填报，然后重新提交

### 5.3 系统健康检查

如遇系统访问异常，可通过以下接口检查后端服务状态：

```
GET http://服务器IP/api/actuator/health
```

正常响应示例：

```json
{
  "status": "UP"
}
```

- `UP`：服务正常
- `DOWN`：服务异常，请联系系统管理员
