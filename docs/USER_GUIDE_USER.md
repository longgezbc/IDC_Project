# IDC 数据中心综合布线项目管理系统 - 普通用户使用指南

> 本文档面向「普通用户」角色，介绍系统功能及操作方法。

---

## 系统概述

IDC 数据中心综合布线项目管理系统采用三端架构，方便不同角色在不同场景下使用：

| 端 | 技术栈 | 访问方式 |
| --- | --- | --- |
| Web 端 | Vue3 + Element Plus | 浏览器访问：`http://服务器IP/` |
| 微信小程序 | uni-app | 微信搜索「IDC项目管家」 |
| 后端服务 | Spring Boot | 由运维部署，普通用户无需关注 |

普通用户可在 Web 端进行项目、文档、任务、客户等信息查询与管理，在小程序端进行移动办公查询。

## 一、角色定位与权限范围

### 1.1 角色定位

- **角色名称**：普通用户
- **角色代码**：`user`
- **角色定位**：只读用户 + 客户管理者
  - 主要职责是查询项目、文档、任务等信息
  - 唯一的写操作权限是「客户管理」
  - 不可参与进度填报、审核、风险预警等核心业务流程

### 1.3 Web 端菜单结构

- **工作台**：数据概览
- **项目管理**：项目列表（只读查看）
- **文档管理**：文档列表（查询/下载，不可上传）
- **进度任务**：进度管理（只读查看任务列表和进度）
- **客户管理**：客户列表（CRUD，重点功能）
- **归档管理**：归档记录查询（只读）
- **数据分析**：统计分析（只读）、审批流程图
- **系统设置**：个人设置（修改密码/个人信息）

### 1.4 小程序端可用功能

普通用户在小程序端可使用：

- 工作台首页
- 项目列表/详情（只读）
- 通知列表
- 个人中心

普通用户在小程序端**不可使用**：

- 进度填报
- 进度审核
- 客户管理
- 风险预警看板
- 项目组管理
- 授权审批

## 二、核心功能操作指南

### 2.1 查看项目信息

**操作路径**：项目管理 → 项目列表

**操作步骤**：

1. 登录 Web 端系统，点击左侧菜单「项目管理」→「项目列表」。
2. 在项目列表页可查看所有可见项目的概要信息（项目编号、名称、客户、状态、进度等）。
3. **搜索**：在顶部搜索框输入项目名称或编号，点击「查询」按钮。
4. **筛选**：通过状态下拉框（进行中/已完成/已归档等）筛选项目。
5. **查看详情**：点击项目所在行的「详情」按钮，进入项目详情页。
6. 详情页可查看项目基本信息、客户信息、项目组成员、关联任务、关联文档等。

**注意事项**：

- 普通用户为只读权限，详情页不会显示「编辑」「删除」「归档」等按钮。
- 项目可见范围受「授权」控制（assignment = 仅授权可见），可能无法看到部分未授权项目。
- 如需查看未授权项目，请联系项目经理申请授权。

---

### 2.2 查看任务进度

**操作路径**：进度任务 → 进度管理

**操作步骤**：

1. 点击左侧菜单「进度任务」→「进度管理」。
2. 选择目标项目，查看该项目下的任务列表。
3. 任务列表显示任务名称、负责人、计划开始/结束时间、实际进度百分比、状态等。
4. **查看甘特图**：点击「甘特图」视图切换按钮，以图形方式查看任务时间轴和进度。
5. 点击任务行可展开查看任务的详细信息、进度日志等。

**注意事项**：

- 普通用户**不可填报进度**，所有进度填报入口均不可见。
- 普通用户**不可审核**任务，审核相关按钮不可见。
- 仅可查看任务列表和甘特图，无法新增/编辑/删除任务。

---

### 2.3 客户管理（重点功能）

**操作路径**：客户管理 → 客户列表

> 客户管理是普通用户**唯一的写操作权限**，可进行完整的新增、编辑、删除操作。

#### 2.3.1 查询客户

1. 点击左侧菜单「客户管理」→「客户列表」。
2. 在顶部搜索框输入客户名称、编号或联系人，点击「查询」。
3. 列表显示客户编号、名称、联系人、电话、邮箱、地址等信息。

#### 2.3.2 新增客户

1. 在客户列表页，点击右上角「新建」按钮。
2. 在弹出的表单中填写以下信息：
   - **客户编号**：必填，唯一标识，不可与已有编号重复
   - **客户名称**：必填
   - **联系人**：必填
   - **联系电话**：必填
   - **邮箱**：选填，需符合邮箱格式
   - **地址**：选填
3. 点击「保存」按钮完成新增。
4. 系统提示「新增成功」，客户列表自动刷新。

#### 2.3.3 编辑客户

1. 在客户列表中，找到目标客户所在行。
2. 点击「编辑」按钮。
3. 在弹出的表单中修改需要变更的信息。
4. 点击「保存」按钮完成编辑。
5. 系统提示「修改成功」。

#### 2.3.4 删除客户

1. 在客户列表中，找到目标客户所在行。
2. 点击「删除」按钮。
3. 系统弹出确认对话框，提示删除影响。
4. 确认无误后，点击「确定」完成删除。

**注意事项（重要）**：

- **客户编号唯一**，新增时不可与已有编号重复。
- **删除客户级联影响**：删除客户后，关联该客户的项目会自动将 `customer_id` 置为 `NULL`，**项目本身不会被删除**，但项目详情中的客户信息将显示为空。
- 删除操作不可恢复，请谨慎操作，建议删除前先与项目经理确认。
- 如客户已被多个项目关联，建议优先考虑「编辑」而非「删除」。

---

### 2.4 下载文档

**操作路径**：文档管理 → 文档列表

**操作步骤**：

1. 点击左侧菜单「文档管理」→「文档列表」。
2. 在顶部搜索框输入文档名称、编号或标签，点击「查询」。
3. 通过文档类型、上传时间等筛选条件缩小范围。
4. 在文档列表中找到目标文档。
5. 点击该行的「下载」按钮。
6. 浏览器弹出下载提示，选择保存位置，完成下载。

**注意事项**：

- 普通用户**不可上传**文档，列表中没有「上传」按钮。
- 普通用户**不可编辑/删除**文档，相关操作按钮不可见。
- 如下载失败，请检查网络连接或联系系统管理员确认文件是否存在。

---

### 2.5 查看统计分析

**操作路径**：数据分析 → 统计分析

**操作步骤**：

1. 点击左侧菜单「数据分析」→「统计分析」。
2. 查看项目统计图表（项目总数、按状态分布、按客户分布等）。
3. 查看任务统计图表（任务总数、完成率、延期率等）。
4. 查看文档统计图表（文档总数、按类型分布等）。
5. 切换「审批流程图」标签，查看各类审批流程的图形化展示。

**注意事项**：

- 统计数据为**全局统计**，不受项目可见范围限制。
- 普通用户仅可查看，不可导出或配置统计报表。

---

### 2.6 修改个人信息

**操作路径**：系统设置 → 个人设置

#### 2.6.1 修改密码

1. 点击右上角用户头像，选择「系统设置」→「修改密码」。
2. 输入原密码。
3. 输入新密码（需符合系统密码复杂度要求，通常为 8 位以上，包含字母和数字）。
4. 再次输入新密码以确认。
5. 点击「保存」按钮完成修改。
6. 修改成功后，建议重新登录。

#### 2.6.2 修改个人信息

1. 点击「系统设置」→「个人信息」。
2. 修改可编辑的字段（如手机号、邮箱、头像等）。
3. 点击「保存」按钮完成修改。

**注意事项**：

- 用户账号、角色等关键字段不可自行修改，如需变更请联系系统管理员。
- 如忘记密码，请联系系统管理员重置。

## 四、注意事项与限制条件

### 4.1 权限限制

1. **普通用户为只读用户**，不可创建/编辑/删除项目和任务。
2. **不可上传文档**，只能下载已有文档。
3. **不可填报进度**，只能查看任务进度和甘特图。
4. **客户管理是普通用户唯一的写操作权限**，其他模块均不可进行写操作。
5. 不可访问以下模块：系统管理、进度审核、风险预警看板、项目组管理、授权审批、项目授权申请。

### 4.2 客户管理注意事项

6. **删除客户级联影响**：删除客户后，关联该客户的项目会自动将 `customer_id` 置为 `NULL`（**不会删除项目本身**），项目详情中的客户信息将显示为空。
7. **客户编号唯一**，新增时不可与已有编号重复，系统会进行校验。
8. 删除操作不可恢复，请谨慎操作。

### 4.3 数据可见范围

9. **项目可见范围限制**：项目授权模式为 `assignment`（仅授权可见），普通用户可能无法看到部分未授权项目。如需查看未授权项目，请联系项目经理申请授权。
10. **统计数据为全局统计**，不受项目可见范围限制，统计分析页面展示的是全系统数据。

## 五、问题排查与支持渠道

### 5.1 常见问题 FAQ

#### Q1：为什么我看不到某个项目？

**A**：项目可见范围受授权控制（assignment = 仅授权可见）。普通用户只能看到被授权的项目。请联系项目经理确认该项目是否已对你授权，如未授权，请申请授权。

#### Q2：为什么我无法下载文档？

**A**：可能原因及排查方法：
- 网络连接异常：检查网络是否正常。
- 文件不存在或已被删除：联系系统管理员确认。
- 浏览器拦截下载：检查浏览器弹窗拦截设置，允许本站点弹窗。
- 权限不足：确认你的账号状态正常，必要时重新登录。

#### Q3：客户删除失败怎么办？

**A**：可能原因及排查方法：
- 客户编号被其他业务引用且存在约束：联系系统管理员排查。
- 网络异常：刷新页面后重试。
- 删除前请确认级联影响：删除后关联项目的 `customer_id` 会置为 `NULL`，项目不会被删除但客户信息会丢失。如只是想暂停使用该客户，建议「编辑」状态而非删除。
- 如反复失败，请联系系统管理员。

#### Q4：忘记密码怎么办？

**A**：普通用户无法自行找回密码，请联系系统管理员通过后台重置密码，重置后请及时修改为个人密码。

#### Q5：为什么没有「上传文档」「新建项目」等按钮？

**A**：普通用户为只读用户，除客户管理外不具备写操作权限，因此相关按钮不可见。如需进行这些操作，请联系项目经理或系统管理员，由具备相应权限的角色处理。

#### Q6：小程序端为什么没有客户管理功能？

**A**：普通用户在小程序端不支持客户管理，客户管理请在 Web 端操作。小程序端主要提供查询和通知查看功能。

### 5.2 项目可见范围说明

- 系统采用「授权可见」机制（assignment 模式）控制项目可见性。
- 普通用户只能看到被显式授权的项目。
- 授权由项目经理或系统管理员通过「项目授权管理」功能配置。
- 如需查看未授权项目，请向项目经理提交授权申请。
- **注意**：统计分析页面的数据为全局统计，不受项目可见范围限制。

### 5.3 系统健康检查

如遇系统访问异常，可访问以下地址检查系统健康状态：

```
http://服务器IP/api/actuator/health
```

正常情况下返回 `{"status":"UP"}`。如返回异常状态或无法访问，请联系系统管理员。

### 5.4 联系支持渠道

遇到无法解决的问题时，可通过以下渠道获取支持：

| 支持类型 | 联系方式 | 适用场景 |
| --- | --- | --- |
| 项目经理 | 通过企业内部通讯工具联系 | 项目授权申请、业务流程咨询、项目信息问题 |
| 系统管理员 | 通过企业内部通讯工具联系 | 账号问题、密码重置、系统故障、权限配置 |
| IT 运维 | 通过企业内部工单系统提交 | 网络访问异常、服务器故障 |

**建议反馈顺序**：先自查 FAQ → 再联系项目经理 → 最后联系系统管理员。
